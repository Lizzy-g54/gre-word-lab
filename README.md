# GRE 词汇练习室

可直接部署到 GitHub Pages 的静态网站。包含中文释义、六选二等价词、跨天续做、每日错词复习与逐项答错统计。

## 使用

打开网站后从“总览”选择词表。未完成的轮次会跨天保留，并在每天重新随机排列剩余项目。整份词表完成后，次日开启新一轮。所有曾答错的单词和词对每天单独复习一次。

学习记录保存在当前网址下的浏览器存储中。若从其他网址迁移，在旧网址的“我的词库 → 迁移学习进度”下载 JSON 文件，再在新网址导入。

## 词库

- 中文释义：用户提供的《学而思 GRE 填空急救 1400 词》
- 等价词：用户提供的《BB 六选二词表（表格速记版）》及《真经 GRE 等价词汇总》

词对用于练习，具体题目仍需结合语境判断。网站没有后端，也不向服务器发送答题记录。
